# statusstamp

statusstamp draws distressed or clean document status stamps in LaTeX.
Automatic stamps can appear on selected pages in the background or foreground;
the package also provides an inline stamp command. Labels, dates, colors,
placement, rotation, scale, opacity, and the repeatable wear pattern are
configurable.

This archive contains the handwritten statusstamp.sty, a PDF manual with its
LaTeX source, two examples with their compiled PDFs, a changelog, and the license. Read
statusstamp-manual.pdf for installation instructions and the option reference.
An illustrated gallery is available in the source repository.

Requirements: LaTeX dated 2020-10-01 or later, TikZ/PGF, xcolor, graphicx,
and the TeX Gyre Heros (qhv) font family. No shell escape or external
generator is required.

Source and examples: https://github.com/cmccomb/statusstamp
