# Changelog

## 0.1.0 - 2026-09-12

- Extract the original distressed SUBMITTED stamp into a standalone package.
- Preserve its default color, proportions, 11-degree rotation, fixed seed,
  and placement behind the text on every page.
- Add text, date, color, opacity, scale, seed, clean-border, page-selection,
  placement, layer, and enable/disable settings, plus an inline stamp command.
- Keep page layout and the document's PGF random sequence unchanged.
- Add examples, documentation, regression checks, and GitHub Actions.
